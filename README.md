# ARKHE. — Modern Luxury Architecture & Interiors

This project is a **React + Vite** single-page website.

## Language / Tech Stack

- **Primary language:** JavaScript (ES modules)
- **Frontend framework:** React 18
- **Build tool:** Vite
- **Styling:** Tailwind CSS (via `@tailwindcss/vite`) + custom CSS
- **Routing:** `react-router-dom`
- **Animations:** `framer-motion`
- **UI icons:** `lucide-react`

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Notes

- Language switching uses `src/context/LanguageContext.jsx`.
- Entry point: `index.html` → `src/main.jsx`.
